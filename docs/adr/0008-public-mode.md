# ADR 0008: 公开模式：一个开关管住占位照片、主人功能和试用次数

日期: 2026-11-15

## 状态

Accepted（板块 7，全站检查第 1 到 3 项，Cecilia 选了推荐的做法）。

## 背景

网站要给老师和朋友打开，但现在有三件事不能直接公开：

1. 地点档案显示 54 张第三方和官网占位照片，规则是公开前必须换掉（没有授权）。
2. 没有登录，`/trips` 和 `GET /api/trips` 会列出数据库里的全部行程，谁都能生成和撤回分享链接。
3. 规划和双模型对比的接口谁都能调用，没有次数限制，花的是 Cecilia 的千问和豆包额度。

## 决定

后端 `.env` 加一个开关 `PUBLIC_MODE`（代码 `app/core/site_policy.py`）。本机开发时关着，一切照旧；网站给别人用时打开：

1. **占位照片不对外**：景点接口不返回 `official-placeholder` 和 `third-party-placeholder` 的照片，后端也不挂 `/media/photos-placeholder`。只显示自己拍的和有授权的照片，没有就写"待补充"。
2. **主人功能要口令**：我的行程、生成分享链接、查询某个版本的分享链接、撤回，要请求头 `X-Owner-Passcode` 等于 `.env` 的 `OWNER_PASSCODE`（用 `secrets.compare_digest` 比）。没设口令时这些功能关掉（403）。打开分享页不要口令。前端遇到 401 时显示口令输入框，口令只存在这台电脑的浏览器里。
3. **规划和对比限次数**：同一个地址每小时 `RATE_PER_CLIENT_PER_HOUR` 次（默认 5），全站每天 `RATE_PER_DAY` 次（默认 50，按武汉时间零点算）；对比一次算 2 次（两个模型各排一份）。带对口令的不限、不计数。超限返回 429 和中文说明。次数记在 SQLite 表 `rate_events`，只存地址的摘要，两天前的自动删掉。
4. 网站前面有反向代理或隧道时，所有请求看起来都来自代理，要打开 `TRUST_PROXY_HEADERS` 用 `X-Forwarded-For` 认人；没有代理时不能打开，否则访客可以伪造地址绕过每小时的限制（全站每天的上限仍然有效）。

## 没选的做法

- 照片：本机也不显示占位照片（Cecilia 自己看资料时会少了参考）；先不处理、上线前拍完实地照片（时间上做不到）。
- 主人功能：公开模式下直接关掉（如果网站放在云服务器，那里的数据库和本机的不是同一个，就没法在公开的网站上分享）；整站加口令（老师和朋友也要输口令）。
- 次数：规划和对比也要口令（老师就不能自己试了）；不限次数，只在模型控制台设消费上限（超了以后整个网站都不能规划，而且没有提示）。

## 代价和还没管住的

- 次数按地址算，同一个网络下的几个人共用每小时的次数；换网络可以多用，但全站每天的上限兜底。
- 没超限时先记一次再处理请求，所以请求后面出错（例如对话不存在）也算一次。
- 路线接口（`/api/routes`，"两点之间怎么走"）和高德安全密钥代理没有限次数，花的是高德的配额（每月 15 万次路径规划）。真要公开很久再考虑。
- 口令是一个共用的字符串，不是账号；只适合"网站主人一个人"的情况。
