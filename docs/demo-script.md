# 演示录屏步骤清单（2 到 3 分钟）

Cecilia 照着录屏用。只演示已经做出来的功能。每一步写了：点哪里、屏幕上应该看到什么、可以说的话（要点，用自己的话说）。

模型每次回答都不一样，所以下面不写"会排出哪几个景点"。排出来什么就讲什么；没通过校验的话，正好演示"不合格的不展示"。

## 录之前（不录进去）

- [ ] 前后端都启动：`corepack pnpm dev:api`、`corepack pnpm dev`（录正式版的话先 `corepack pnpm build`，再用 `corepack pnpm --filter @wuhanmemory/web exec next start` 启动前端）。
- [ ] **打开公开模式录**：`apps/api/.env` 里 `PUBLIC_MODE=true`、设好 `OWNER_PASSCODE`，重启后端。这样地点档案里的第三方占位照片不会被录进去。先在 `/trips` 输一次口令，这样后面生成分享链接不用再输，也不受试用次数限制。
- [ ] 路线预热过（`corepack pnpm routes:prewarm`），交通时间直接从缓存取。
- [ ] 浏览器窗口 1280 宽左右，关掉别的标签页和通知；地址栏不要露出别的网站。
- [ ] `/map` 点对话纸上的"新对话"，清掉旧对话。
- [ ] 先自己试一遍第 2 步那句话，确认两个模型都能用（`corepack pnpm llm:smoke`）。
- [ ] 想好排行程那十几秒说什么（见第 2 步），或者录完把等待剪短，并在视频里说一句"这里剪掉了等待"。

## 录制

| # | 大约时间 | 操作 | 应该看到 | 可以说的要点 |
|---|---|---|---|---|
| 1 | 0:00–0:15 | 打开首页 `/` | 暗房桌面风格的首页和四个入口 | 我是谁；这是一个用对话规划武汉行程的网站；想解决的问题是"大模型排的行程看起来对，其实开放时间和交通可能是编的" |
| 2 | 0:15–0:50 | 进地图工作台 `/map`，模型选千问，输入"武汉两天，喜欢历史和美食，坐地铁，11 月 28 日出发"，发送 | 对话纸上出现规划进度（理解需求、从景点库挑候选、模型排三份方案、查真实交通时间、校验……），十几秒后右边出现方案对比卡 | 模型只负责听懂话和挑景点、定顺序；景点资料来自有来源的景点库，交通时间由程序查高德，钟点由程序推；同一句话按三种侧重排三份 |
| 3 | 0:50–1:20 | 在对比卡上切换两份方案；点"地图上看 第 1 天""全部" | 地图上的路线和带顺序的图钉跟着变；对比表里的交通时间、步行距离、门票都是程序算的 | 三份方案的区别是程序定的规则，不是让模型自己说"不一样" |
| 4 | 1:20–1:45 | 往下看行程卡的一天，指一下一站的开放时间、"待确认"标记，和总卡上的校验印章、警告 | 每站有开放、预约、门票、支付和核实状态；总卡上写着哪个模型排的、第一版有几处错误、修正过没有 | 每份行程给人看之前都用 `validate_itinerary` 校验；有错误先让模型修正一次，还不对就不展示；资料多数还是占位，所以有警告，这一点我如实标出来了 |
| 5 | 1:45–2:00 | 在行程总卡上点"生成分享链接"，再点"打开分享页" | 新标签页打开只读的明信片：邮戳是今天的日期，下面是地图和行程 | 分享链接指向这一版的快照，原行程以后改了也不变 |
| 6 | 2:00–2:25 | 打开模型对比 `/compare`，点右边历次对比里的一条（不现场发新的，省时间） | 左右两张打字纸、中间评分卡：第一版错误、修正后、耗时、token | 同一份偏好、同一份候选，只换模型；指标全部由程序算。批量评测的结果文件在 GitHub 上，样本少，所以我没下"哪个模型更好"的结论 |
| 7 | 2:25–2:45 | 打开地点档案 `/places`，点一个景点 | 每条信息下面写来源、核实方式、核实日期、有效期 | 每个景点必须有坐标和来源；会变的信息有过期时间，检查脚本强制执行 |
| 8 | 2:45–3:00 | 回到首页或停在 README | — | 技术栈一句话（Next.js、FastAPI、高德、千问和豆包）；代码在 GitHub，开发过程和每个决定都有记录；代码是我和 AI 编程助手一起写的，需求、设计决定和验收由我负责 |

## 录完

- [ ] 把 `PUBLIC_MODE` 改回 `false`，重启后端（本机开发照旧）。
- [ ] 想撤回录屏里那个分享链接的话，在 `/trips` 点"撤回"。
- [ ] 检查视频里没有露出 `.env`、终端里的 key、浏览器书签和通知。

## 万一

- 规划超过 1 分钟没出来：多半是模型那边慢。换另一个模型再发一次，或者用之前排好的对话（`/trips` 里点"打开"）接着演示。
- 显示"这份行程没通过校验"：照实讲，这正是校验在起作用；再演示另一份通过的方案。
- 地图没加载出来：看后端有没有在跑（地图请求要经过后端加安全密钥）。
