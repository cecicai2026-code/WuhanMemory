# 景点资料填写模板

数据格式 2026-11-15 由 Cecilia 确认，字段说明见 `docs/architecture/data-model.md`。

每个景点复制一份下面的表填写，填好后发给 Claude，由 Claude 转成 `data/pois/<景点id>.json`。
不用写 JSON，也不用管格式，按顺序填就行。

## 怎么填

- 每一条后面的"核实方式"四选一：
  - **实地**：你去现场看到或问到的。写上去的日期。
  - **核对**：你自己看过官网、公众号或售票页面，确认没问题，但没在现场核对。写上看的日期和链接。
  - **占位**：你还没看，先让 Claude 按官网填，界面上会标"待确认"。
  - **不知道**：空着就行，Claude 会写 `TODO(Cecilia)`。
- 日期都写成 `2026-11-15` 这样。
- 不确定的就空着，不要估。

### 六、照片

把照片放进文件夹 `data/photos/<景点id>/`（例：`data/photos/yellow-crane-tower/`），文件名用英文和数字。每张照片一行：

| 文件名 | 一句话说明（给看不到图的人读） | 拍摄日期 | 是谁拍的 |
|---|---|---|---|
|  |  |  |  |

照片要求：横图优先，长边 2000 像素左右即可；每个景点 3 到 6 张；至少一张能看出景点全貌；拍照机位的示例照片单独标出来。手机原图里带的位置信息，提交前 Claude 会提醒你是否要去掉。

## 坐标怎么拿

推荐用高德坐标拾取器：打开 `https://lbs.amap.com/tools/picker`，搜索景点名，点景点大门或主入口的位置，复制右边的坐标（经度在前，纬度在后）。这个工具给出的坐标就是高德地图用的坐标系（GCJ-02），可以直接填。
