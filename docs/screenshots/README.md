# 截图

README 用的截图放在这里，由 Cecilia 截。页面上本来就不显示 key，不用担心截进去。

建议截这几张（电脑宽度 1280 左右，手机用浏览器的手机模式 375 宽）：

| 文件名 | 截什么 |
|---|---|
| `map-desktop.png` | 地图工作台：左边一段对话，中间地图上画着第 1 天的路线，右边方案对比卡和行程卡 |
| `map-phone.png` | 手机上的地图工作台：地图在上，下面是行程 |
| `plan-card.png` | 行程卡的一天：时间线、每段交通、开放时间和"待确认"标记 |
| `compare.png` | 模型对比：两张打字纸和中间的评分卡 |
| `places-detail.png` | 一个景点的档案页：条目下面的来源、核实日期和有效期 |
| `share.png` | 分享页：明信片和地图 |
| `trips.png` | 我的行程：一段对话下面的几份方案和版本 |

注意：现在的景点照片是第三方占位，不要截进要公开的图里（或者截图前在 `.env` 打开 `PUBLIC_MODE`，占位照片就不显示）。
