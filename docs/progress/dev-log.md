- 设计规范又改成 v3。我找到了真正想要的风格，给了三张参考图：暗房里的木桌，胶卷穿过看片器、照片晾在绳子上、信纸摆在桌上。全站改成这种"暗房桌面"风格，界面元素都做成实物。地点档案定为三幕：滚动走胶卷看全部景点，点击后照片挂上晾片绳、盘子里是四个主题（景点概览、游玩建议、景点图册、周边美食），选主题后看桌上的信纸。交互改为悬停有反应、点击才进入，不用拖拽。
- 这个风格需要立体渲染，所以决定引入 three.js；地图、对比、行程这些工具页面仍用普通网页排版，保证好用。
- 第一版平面小样我觉得太丑、没有立体感，于是改用 three.js 做真正有光影的样片。我允许 Claude 启动只读的本地预览自己看效果（只显示 `docs/design/prototypes` 文件夹，不装依赖）。
- 胶卷幕按我的意见改了一轮：材质更真实（黄铜反光、漆面、木纹凹凸、接触阴影），鼠标指到哪一格看片器就滑到哪一格并换铭牌，胶卷加长并用黄铜箭头按组切换，点击后不再出现红色手写字。
- 接着做了晾片幕（照片夹在绳子上、显影盘里四张主题卡）和纸页幕（信纸逐字打出、四个主题各有贴纸、景点图册是散落的照片），三幕已经连通。样片里的照片是程序画的示意图，景点名是示例，纸上的事实都写"待补充"。
- 设计规范第 8 节按样片重写，并定下一条：界面提示不用红色手写字，手写体只出现在纸面上、用蓝灰色。
- 遇到的问题：对话窗口不在前台时，网页动画会暂停，截图看到的是没动起来的画面。解决办法是给样片加了一个手动推进动画的调试入口。
