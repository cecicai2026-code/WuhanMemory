### 板块 0：准备

- 读完现有代码。保留 `LLMGateway`、地图 provider 接口、FastAPI 入口和行程数据结构；前端界面、假地图、mock 行程数据和 mock 接口都要重写。
- 写了 ADR 0003：景点资料以 JSON 文件为准，运行时用 SQLite，读写经过 repository 层；路线缓存也放在 SQLite 里，不用 Redis。
- 环境变量拆成两个文件：后端 `apps/api/.env`，前端 `apps/web/.env.local`。选这个做法是为了让后端的 key 和前端在文件上就分开。
- 申请并填好了千问、豆包、高德的 key。第一次把高德 JS key 和安全密钥填成了同一串，检查后改正。目前只检查了格式，真实调用要等板块 3 和板块 4。
- 设计方向改了：交互和视觉参考 trevornoah.com 和 laxspace.co，字体和圆角参考 Apple；首页改成滚动叙事的展示页，地图工作台移到 `/map`；配色是墨色加金色与浅色交替。写成 `docs/design/design-system.md` 草案。
- 补充规则：我还没提供的照片和简介先用网上资料占位，照片只用可自由使用授权的图，简介用自己的话概括，全部标明来源和"占位"。
- 看过第一版预览后我又改了意见，设计规范改成 v2：配色统一为黑金，去掉浅色章节；字体不参考 Apple，改为参考两个网站的排版（极粗的大字配极细的小字）；新增一组黑金插画；动效要更丝滑（惯性滚动、自定义光标、换页转场）。

- 设计规范又改成 v3。我找到了真正想要的风格，给了三张参考图：暗房里的木桌，胶卷穿过看片器、照片晾在绳子上、信纸摆在桌上。全站改成这种"暗房桌面"风格，界面元素都做成实物。地点档案定为三幕：滚动走胶卷看全部景点，点击后照片挂上晾片绳、盘子里是四个主题（景点概览、游玩建议、景点图册、周边美食），选主题后看桌上的信纸。交互改为悬停有反应、点击才进入，不用拖拽。
- 这个风格需要立体渲染，所以决定引入 three.js；地图、对比、行程这些工具页面仍用普通网页排版，保证好用。
