## 四、已经确认没问题的

- 每个页面在手机宽度（375px）都没有横向滚动：首页、地点档案、景点详情、地图工作台、模型对比、我的行程、分享页。
- 键盘：全站有统一的黄铜色聚焦外框；`/map` 用 Tab 能依次走到菜单、底部面板的纸签、地图上的每个图钉（图钉是按钮，能打开卡片）、2D/3D 拨杆、方案切换、"地图上看 第 N 天"、行程卡里的景点链接和"两点之间怎么走"的下拉框；卡片和菜单能用 Esc 关上。
- 空状态：`/map` 没有行程时写怎么说；`/compare` 没有选中的对比、没有历次对比时都有说明；`/places` 没有景点时有说明；`/trips` 没有行程时有说明和去地图工作台的按钮。
- 出错：后端连不上时，`/places`、`/places/[id]`、`/map`（地图照样显示、写明没有图钉的原因）、`/compare`、`/trips`、分享页都写明原因；地图没有 key 或加载失败时有说明。
