# WuhanMemory 设计规范

版本: v3，2026-11-14
状态: 方向已由 Cecilia 确认。地点档案三幕以 `docs/design/prototypes/` 里的样片为准；其余页面（首页、地图、对比、行程）还没有样片，做的时候再确认。

v3 的来由：Cecilia 提供了三张参考图（胶卷和看片器、晾片绳和显影盘、桌上的信纸），确定全站采用这种"暗房桌面"风格，并规定了地点档案的三步浏览方式。v3 取代 v1、v2 的配色、字体和版式；v2 里的插画、占位内容规则保留并改写。

本文件取代开工说明第 5 节原来的设计方向。板块 1 起所有界面按本文件实现；要改数值时先改本文件，再改代码。

## 1. 设计方向

一句话：**整个网站是暗房里的一张木桌，每个页面是桌上的一个场景。**

### 1.1 对三张参考图的分析

| 方面 | 参考图里的做法 |
|---|---|
| 场景 | 每个画面都是一张深色木桌的局部，像从上方或正前方看过去。内容不是放在"网页"上，而是放在桌上的实物里：胶卷、看片器、照片、盘子、信纸 |
| 光 | 只有一盏暖色的灯。画面中间亮，四周很快暗下去，边缘是黑色暗角。物件有柔和的投影，所以显得立体 |
| 颜色 | 很少的几种：黑、红褐色的木头、墨绿色的器物、黄铜、米黄色的纸，再加一个很小的樱桃红亮点。整体偏暗、偏暖，像暗房的安全灯 |
| 字 | 四种声音各司其职：等宽大写小字是"系统标注"（场景编号、计数、返回）；斜体衬线字是"标题"；打字机字是"纸上的正文"；红色手写字是"旁人的批注"（箭头、提示） |
| 物件 | 都是有年代感的实物：胶卷罐、带铜框的看片器、带齿孔的胶片、木夹子、白边照片、不锈钢盘、竹夹、羽毛笔、耳机、相机贴纸、书 |
| 交互暗示 | 界面元素被做成物件的一部分：看片器上的红色旋钮、照片上的夹子、纸上的横线就是输入框 |
| 排版 | 四角是很小的标注字，中间留给物件。几乎没有传统的按钮和卡片 |

### 1.2 学什么，不学什么

- 学：场景化、单一光源、少量颜色、四种字的分工、把界面做成物件。
- 不照搬：参考图里的具体物件造型、文字内容、照片和版面位置。本项目的物件、文案和照片都是自己的，并加入武汉和旅行的元素。
- 早先参考的 trevornoah.com 和 laxspace.co 只保留两点：丝滑的动效节奏，以及物件随滚动进出画面的手法。

## 2. 页面和场景

每个页面是一"幕"。左上角显示幕的编号和名称，右上角显示由程序数出来的计数，左下角是"← 回到桌面"。

| 路径 | 幕 | 桌上是什么 | 说明 |
|---|---|---|---|
| `/` | 桌面 | 整张桌子的全景，往下滚动时镜头依次经过各个物件 | 首页。每个物件是一个入口：胶卷罐通往地点档案，摊开的地图通往地图工作台，两台打字机通往模型对比，笔记本通往我的行程 |
| `/places` | 胶卷 | 胶卷罐、穿过看片器的一条胶片 | 景点概览，见第 8.1 节 |
| `/places/[id]` | 晾片 | 晾片绳上的全部景点照片、显影盘里的四个主题 | 景点详情，见第 8.2 节 |
| `/places/[id]/[主题]` | 纸页 | 桌上的一张信纸和几个小物件 | 某个主题的内容，见第 8.3 节 |
| `/map` | 灯箱 | 嵌在桌面里的黄铜边灯箱，里面是地图；旁边是打字纸和索引卡 | 地图工作台，见第 9.1 节 |
| `/compare` | 两台打字机 | 两张并排的打字纸，中间一张评分卡 | 模型对比，见第 9.2 节 |
| `/trips` | 笔记本 | 一本摊开的笔记本，行程是夹在里面的印样 | 我的行程，见第 9.3 节 |
| `/s/[slug]` | 明信片 | 一张明信片和一张折页 | 分享页，只读 |

导航：页面顶部不放传统导航栏。四角的标注字承担导航：左上是当前幕，左下是"← 回到桌面"，右下是一个黄铜圆按钮"开始规划"（通往 `/map`），右上是计数和一个菜单按钮。菜单打开后是桌面的俯视小图，点物件跳转。

黄铜就是原来的金色：v2 的"黑金"在 v3 里变成"黑底、黄铜、暗红木头"。金色仍然只用在要用户注意的地方。

### 3.2 光

- 每一幕只有一个主光源，位置在画面上方偏左，颜色是暖白（约 `#FFD9A8`）。
- 暗角：画面边缘用径向渐变压到 `--black`，中心到边缘的亮度差约为三比一。
- 所有物件有朝右下方的柔和投影，投影颜色是 `rgba(0, 0, 0, 0.55)`，越高的物件投影越长越虚。
- 没被选中的照片罩一层暗房红（`#A8321F`，叠加方式为正片叠底），被选中的恢复原色并被灯照亮。
- 全页一层细颗粒（不透明度 6%）。

### 3.3 状态色

| 含义 | 深色底上 | 纸上 | 做成什么 |
|---|---|---|---|
| 已核实、校验通过 | `#7FB094` | `#2F6B4F` | 一个绿色小印章 |
| 待确认、占位 | `#8FA3B5` | `#44607A` | 一个蓝灰色铅笔批注 |
| 已过期、校验未通过 | `#E0624A` | `#A8321F` | 一个红色印章 |

状态必须同时有文字，不只靠颜色。

### 3.4 对比度

| 文字 | 背景 | 对比度 |
|---|---|---|
| 纸色 `#E9DFC6` | 暗角黑 `#070504` | 15.34 |
| 纸色 `#E9DFC6` | 木头暗部 `#4A1610` | 11.2 |
| 纸色 `#E9DFC6` | 木头 `#6B2216` | 8.49 |
| 次要文字 `#B3A68C` | 木头暗部 | 6.19 |
| 标注字 `#8F836C` | 暗角黑 | 5.45 |
| 黄铜 `#C9A45C` | 木头暗部 | 6.33 |
| 墨 `#2A2420` | 纸 `#E9DFC6` | 11.54 |
| 淡墨 `#6B5E4C` | 纸 | 4.75 |
| 红褐 `#A8321F` | 纸 | 5.04 |
| 铅笔蓝灰 `#44607A` | 纸 | 4.95 |

正文不直接放在亮部的木头上。长段文字一律放在纸上或暗角黑底上。

## 4. 字体

四种字各有固定的用途，不混用。全部是开源字体（OFL 许可），通过 `@fontsource` 安装到项目里，不依赖国外的字体服务。

| 声音 | 用在哪里 | 英文和数字 | 中文 |
|---|---|---|---|
| 标注 | 四角的幕编号、计数、返回、胶片边缘印字、铭牌 | IBM Plex Mono，400，全大写，字间距 0.14em | 思源黑体 400，字间距 0.3em |
| 标题 | 每一幕的标题、景点名、胶卷罐上的字 | Cormorant Garamond，斜体，500 | 思源宋体（Noto Serif SC）600 |
| 纸上正文 | 信纸、索引卡、打字纸上的内容 | Courier Prime，400 | 霞鹜文楷（LXGW WenKai）400 |
| 批注 | 只出现在纸面上的手写字："待补充"、署名 | Caveat，500 | 系统楷体（样片用的是这个）；需要更像手写时用马善政毛笔楷书 |

```css
--font-label: "IBM Plex Mono", "Noto Sans SC", "PingFang SC", monospace;
--font-title: "Cormorant Garamond", "Noto Serif SC", "Songti SC", serif;
--font-paper: "Courier Prime", "LXGW WenKai", "Kaiti SC", serif;
--font-note: "Caveat", "Ma Shan Zheng", "Kaiti SC", cursive;
```

### 4.1 字号

| 名称 | 电脑 | 手机 | 字体 | 用途 |
|---|---|---|---|---|
| 幕标题 | 44px | 30px | 标题 | 每一幕上方中间的标题，例如当前景点名 |
| 物件上的大字 | 56px | 36px | 标题 | 胶卷罐、书脊、明信片上的字 |
| 纸上标题 | 26px | 22px | 纸上正文，加粗 | 信纸上的问题或小标题 |
| 纸上正文 | 17px | 16px | 纸上正文 | 行高 1.8 |
| 批注 | 22px | 20px | 批注 | 纸上的手写字，蓝灰色，略微倾斜（2 度以内） |
| 标注 | 12px | 11px | 标注 | 四角和物件上的小字 |
| 界面小字 | 14px | 14px | 标注或纸上正文 | 表单、状态 |

- 中文没有斜体，标题用思源宋体的正体，靠字重和字号区分。
- 手写字只用于纸面上的短句（不超过 12 个字），用铅笔蓝灰色，不用红色。不叠在场景画面上，也不用于正文和任何必须读清楚的信息。
- 开放时间、票价这类关键信息一律用纸上正文字体，保证清晰。

## 5. 版面和间距

- 每一幕占满一个屏幕（`100vh`），内容不够一屏时居中，超过一屏时在场景内滚动或推进镜头。
- 四角留出 64px（手机 20px）的边距放标注字。物件不压住标注。
- 一幕里的主体物件不超过三件，其余是不抢眼的点缀（最多三件小物件）。
- 物件摆放不要求对齐网格，可以有 2 到 6 度的随意旋转，像手放在桌上的。纸上的文字内部严格左对齐、等行距。
- 基础间距单位 4px。纸的内边距：电脑 48px，手机 24px。
- 断点：手机小于 734px，平板 734 到 1068px，电脑大于 1068px。

## 6. 材质和物件

### 6.1 材质

| 材质 | 做法 |
|---|---|
| 木头 | 红褐色，有横向木纹和细微的反光。使用可自由使用（CC0）的木纹贴图，或用代码生成 |
| 黄铜 | 有拉丝感的金属，边缘有一条亮的高光线 |
| 墨绿漆面 | 哑光，边缘有很弱的反光 |
| 纸 | 米黄色，有很淡的纤维和不均匀的色斑，边缘略深，四角不完全方正 |
| 胶片 | 半透明的橙褐色，有齿孔和边缘印字 |
| 照片 | 哑光相纸，四周一圈白边（宽度是照片宽的 5%） |
| 不锈钢 | 拉丝，盘底有很弱的环境反光 |

### 6.2 物件清单

第一批要做的物件，都带有武汉或旅行的元素：

| 物件 | 用在哪里 | 上面有什么 |

| 胶片 | 胶卷幕 | 齿孔、格号、边缘印字 `WUHAN MEMORY` |

| 显影盘、竹夹 | 晾片幕 | 盘里四张主题卡 |
| 信纸 | 纸页幕、地图工作台的对话 | 打字机字 |

物件不描摹参考图里的造型。物件上不印任何编造的数字或信息。

### 6.3 物件怎么做

| 方式 | 适合什么 | 谁来做 |
|---|---|---|
| 用代码搭的立体模型 | 形状简单的物件：罐子、看片器、盘子、纸、照片、绳子、夹子、书。由圆柱、方块、平面组合，加材质和灯光 | Claude 直接写 |
| 可自由使用（CC0）的现成模型和贴图 | 木纹、金属贴图；形状复杂的物件 | Claude 找到来源并记录许可，Cecilia 确认后下载 |
| 平面贴纸插画 | 相机、车票、热干面等点缀 | Claude 用代码画线描版本；如果要更精细的，由 Cecilia 用图像生成工具按 Claude 写的提示词生成 |

说明：参考图里的画面是专业建模和渲染的结果。用代码搭的模型可以做到同样的氛围（光、颜色、构图、动效），但物件的精细程度会低一些。要达到参考图的精细度，需要专门制作的 3D 模型。

## 7. 界面组件

传统的按钮、卡片、标签都换成对应的实物。

| 组件 | 做成什么 | 细节 |
|---|---|---|
| 主按钮 | 黄铜圆按钮或黄铜铭牌 | 高 48px，墨色字，标注字体。悬停时高光扫过，按下时下沉 2px |
| 次按钮 | 一张小纸签 | 纸色底，墨色字，略微旋转。悬停时抬起并转正 |
| 文字链接 | 标注字体的小字加箭头 | 悬停时变亮；当前项是黄铜色并带下划线 |
| 输入框 | 纸上的一条横线 | 输入的字用纸上正文字体，光标是闪烁的竖线。提示语是淡墨色的纸上正文字体 |
| 信息卡 | 索引卡或信纸 | 纸色底，1px 淡墨色横线格 |
| 状态标签 | 印章或铅笔批注 | 见 3.3 |
| 开关、切换 | 樱桃红旋钮或拨杆 | 例如 2D/3D 切换是灯箱旁的一个拨杆 |
| 加载 | 显影 | 内容从暗房红的单色逐渐显出原色，不用转圈图标 |
| 提示消息 | 一张从屏幕外推进来的便条 | 纸上正文字体 |
| 四角标注 | 标注字体 | 只显示真实的值：幕的编号和名称、景点数量、当前格号、当前模型、校验结果 |

所有可点击元素的点击范围不小于 44 × 44px。键盘聚焦时，物件周围出现一圈 2px 的黄铜色外框。

## 8. 地点档案的三幕

浏览路径：**胶卷（看全部景点）→ 晾片（进入一个景点）→ 纸页（看一个主题）**。

三幕都有可以操作的样片，Cecilia 已确认方向。样片是这一节的依据，文字和样片不一致时以样片为准：

| 幕 | 样片文件 |
|---|---|
| 胶卷 | `docs/design/prototypes/darkroom-rolls.html` |
| 晾片 | `docs/design/prototypes/darkroom-line.html` |
| 纸页 | `docs/design/prototypes/darkroom-page.html` |
| 共用的贴图、材质、舞台和样式 | `docs/design/prototypes/common.js`、`common.css` |

样片是设计稿，不是网站代码。里面的照片是程序画的示意图，18 个景点名是示例清单，板块 1 实现时换成真实数据。

三幕共同的规则：
- 鼠标悬停有反应，点击才进入下一幕，不用拖拽。
- 每一幕都能回到上一幕，并停在刚才看的那个景点。地址里带着景点和主题，刷新或分享链接后看到的是同一个画面。
- 幕与幕之间目前是镜头推近加黑幕过渡。物件飞到新位置的转场（第 10.3 节 G4）是后续的加强项。

### 8.1 第一幕：胶卷（`/places`）

画面：
- 左边立着一个墨绿色胶卷罐，黄铜盖，罐身竖排写着这一卷的名字，旁边一行小字是卷号和总格数。
- 一条略带起伏的橙色胶片从罐子的出片口拉出来，横贯画面。每一格是一个景点的照片，格的左下角印着格号。
- 一个墨绿色的看片器骑在胶片上：黄铜画框、画框四角的螺丝、玻璃屏、顶部把手、侧面的樱桃红旋钮。画框里是当前景点的照片，原色；下方的黄铜铭牌刻着景点名。
- 胶片上其他格罩着暗房红，当前这一格是原色。
- 画面上方中间：一行标注（第几格 / 共几格）和标题（当前景点名）。右上角标注卷数和总格数，由程序数出来。
- 底部中间：左右两个黄铜圆按钮，中间是一排刻度和"01 — 05 / 18"这样的范围。

分组：
- 胶片很长，按每组 5 格显示。当前组的 5 格排在看片器可以到达的位置，下一组的头几格从右边缘露出来。
- 刻度每个景点一条：不在当前组的最矮，当前组的较高，当前景点的最高并且是黄铜色。

操作：
- **鼠标悬停在当前组的某一格上**：看片器沿胶片滑到那一格，滑动时带一点惯性倾斜。画框里的照片像显影一样换成那个景点，铭牌和上方标题同步更换。
- **箭头按钮**：切换到上一组或下一组。胶片平滑滑过，罐子顶上的轴跟着转。按钮悬停时抬起、有一道高光扫过、箭头微移；到头时变暗不可点。
- **滚轮和方向键**：一格一格地走，走到组的边界自动换组。PageUp 和 PageDown 换组。
- **悬停在露出来的下一组的格上**：那一格略微抬起并褪去红色，点击后换到那一组。
- **点击任意一格或看片器**：镜头推近到看片器，四周暗下去，底部显示景点名，然后进入晾片幕。回车键效果相同。
- **换一卷**（按区域筛选）：点击胶卷罐。样片里还没做，实现时旧胶片收回罐内，新胶片拉出。

操作：

- **悬停盘里的主题卡**：和照片的反应一致。卡片从盘里抬起、转向用户、放大、被照亮，其余三张变暗，竹夹移到这张卡旁边，盘子上方的提示字隐去。

## 10. 动效和交互

### 10.1 原则

- **悬停有反应，点击才进入**。全站不使用拖拽作为必要操作。
- 界面上的提示文字用标注字体或标题字体，不用红色手写字叠在画面上。手写体只出现在纸面上。
- 所有物件对鼠标有统一的反应：抬起（向用户方向移动）、放大、转正、被照亮、投影变长变虚。离开时带一点惯性落回。
- 动作要有重量：启动快，落下慢，不匀速，不弹跳。

### 10.2 时间和缓动

| 名称 | 时长 | 用途 |
|---|---|---|
| 微交互 | 200ms | 按下、旋钮 |
| 悬停 | 450ms | 物件抬起和落下 |
| 显影 | 700ms | 照片从暗房红变为原色、内容出现 |
| 走片 | 900ms | 胶片走一格、照片切换 |
| 转场 | 1400ms | 幕与幕之间的镜头移动和物件重组 |

```css
--ease-silk: cubic-bezier(0.16, 1, 0.3, 1);
--ease-inout: cubic-bezier(0.65, 0, 0.35, 1);
```

### 10.3 全局效果

| 编号 | 效果 | 做法 |
|---|---|---|
| G1 | 惯性滚动 | 电脑上给滚动加一点惯性。方向和距离仍由用户控制 |
| G2 | 灯光跟随 | 鼠标移动时，主光源的位置轻微偏向鼠标，物件的高光和投影跟着变化 |
| G3 | 镜头视差 | 鼠标移动时整个场景有 1 到 2 度的轻微转动，产生纵深感 |
| G4 | 幕间转场 | 物件不消失再出现，而是飞到新位置：胶片格变成晾着的照片，主题卡变成信纸 |
| G5 | 光标 | 电脑上光标是一个小的黄铜圆点。在可点击的物件上变成圆环，里面是"查看"、"进入"、"切换"等标注字 |
| G6 | 开场 | 每次访问的第一个页面：黑屏，灯亮起，桌面显出。不超过 2 秒，点击可跳过 |
| G7 | 颗粒和暗角 | 见 3.2 |

### 10.4 规则

- 只对 `transform` 和 `opacity` 做动画（立体场景内由渲染引擎处理）。
- 任何内容在 1.5 秒内必须可读、可点。
- 系统开了"减弱动态效果"时：关掉 G1、G2、G3、物件的飞行和摆动，转场改为淡入淡出，走片改为直接切换。
- `/map` 页面不使用 G2、G3 和任何装饰性动效。
- 检测到帧率持续偏低时自动降级：关闭实时阴影、颗粒和灯光跟随。

## 11. 实现方式和性能

- 地点档案三幕和首页是立体场景，使用 `three.js` 和 `@react-three/fiber`（React 里写立体场景的库）渲染。这改变了 v2"不引入 3D 引擎"的决定，原因是参考图的光影和纵深用纯 CSS 做不出来。
- `/map`、`/compare`、`/trips` 用普通的网页排版加贴图、阴影和 CSS 的 3D 变换实现，不用立体引擎，保证好用和加载快。
- 场景里的文字尽量用真正的网页文字叠在场景上，保证清晰、可选中、读屏软件可读。
- 每个立体场景同时有一份普通的网页结构（景点列表、主题链接、正文），用于键盘操作、读屏软件、搜索引擎，以及立体场景加载失败时的备用显示。
- 手机上：使用简化的场景（物件更少、无实时阴影、固定光源）；性能不足的设备直接显示平面版本。
- 照片按需加载；场景首次加载的资源控制在 3MB 以内。
- 新增依赖都是开源许可，由 Cecilia 在 Mac 终端安装，板块 1 开工时给出命令并确认。
