# WuhanMemory 设计规范

版本: v1 草案，2026-11-14
状态: 方向已由 Cecilia 确认（首页结构、配色、字体、圆角、占位内容）；具体数值待她看过预览后确认。

本文件取代开工说明第 5 节原来的设计方向。板块 1 起所有界面按本文件实现；要改数值时先改本文件，再改代码。

## 1. 设计方向

三个来源，各取一部分：

| 来源 | 取什么 | 不取什么 |
|---|---|---|
| trevornoah.com | 超大标题、随滚动出现的内容、图片飘入、章节变色、胶囊按钮、悬浮导航 | 它的深蓝和粉色、拼贴人像 |
| laxspace.co | 黑幕开场、屏幕中央的 3D 主体、压在屏幕底边的超大文字、四角的小号技术信息、黑幕转场 | 它的字体和具体版式 |
| Apple 官网 | 字体、字号层级、圆角、留白、深浅章节交替、毛玻璃导航 | Apple 的蓝色链接色 |

自己的部分：墨色加金色的配色，以及"城市档案"的气质。动效是为了把内容讲清楚，每一处动效都要能回答"它帮用户看懂了什么"。

只参考交互手法和排版方式，不复制参考网站的图片、文字、代码和字体文件。

## 2. 页面结构

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 首页（展示页） | 滚动叙事，介绍武汉、景点和这个网站能做什么。首屏有通往地图的主按钮 |
| `/map` | 地图工作台 | 核心功能：AI 对话 + 地图 + 行程面板。打开就能用，不需要滚动 |
| `/places` | 地点档案 | 大图卡片网格，可筛选 |
| `/places/[id]` | 景点详情 | 滚动叙事的单个景点页 |
| `/compare` | 模型对比 | 千问和豆包并排 |
| `/trips` | 我的行程 | 生成过的行程列表 |
| `/s/[slug]` | 分享页 | 只读 |

导航项：首页标志、**地图**、**地点档案**、**模型对比**、**我的行程**，最右边是金色胶囊按钮"开始规划"，指向 `/map`。

首页是展示页，但文书里讲的核心功能在 `/map`。所以首页任何一屏都要能一步到达 `/map`：导航栏的"开始规划"始终可见。

深色和浅色两套，按章节交替使用。金色是唯一的强调色。

|---|---|---|---|
| 背景 | `--bg` | `#0E0F11` | 页面底色 |
| 卡片 | `--surface` | `#17181B` | 卡片、面板 |
| 浮层 | `--surface-raised` | `#1F2125` | 悬停、弹出层、输入框 |
| 细线 | `--line` | `#2A2C31` | 分隔线、边框 |
| 主文字 | `--text` | `#ECE7DC` | 标题和正文 |
| 次要文字 | `--text-secondary` | `#A8A396` | 说明、时间、来源 |
| 弱文字 | `--text-muted` | `#857F73` | 占位提示、角落信息 |
| 金 | `--gold` | `#C9A45C` | 强调字、主按钮、选中状态 |
| 亮金 | `--gold-hover` | `#DDBB78` | 悬停 |
| 暗金 | `--gold-line` | `#8A7242` | 细线、次要按钮边框 |
| 金上文字 | `--on-gold` | `#0E0F11` | 金色按钮上的字 |

### 3.2 浅色（纸）

| 名称 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 背景 | `--bg` | `#F5F5F7` | 页面底色 |
| 卡片 | `--surface` | `#FFFFFF` | 卡片、面板 |
| 浮层 | `--surface-raised` | `#FFFFFF` | 弹出层 |
| 细线 | `--line` | `#D2D2D7` | 分隔线、边框 |
| 主文字 | `--text` | `#1D1D1F` | 标题和正文 |
| 次要文字 | `--text-secondary` | `#6E6E73` | 说明、时间、来源 |

| 暗金 | `--gold-line` | `#B89650` | 细线、次要按钮边框 |

### 3.3 状态色

| 含义 | 深色底 | 浅色底 | 用在哪里 |
|---|---|---|---|
| 已核实、校验通过 | `#7FB094` | `#236B4C` | 来源标记、校验结果 |
| 待确认、占位内容 | `#8FA3B5` | `#4F6B82` | 还没核实的信息、网上找来的占位照片和简介 |
| 已过期、校验失败、出错 | `#E0765F` | `#B5432E` | 过期数据、错误提示 |

不用黄色和橙色表示警告，避免和金色混淆。状态不能只靠颜色区分，必须同时有文字（例如"待确认"）。

### 3.5 深浅怎么交替

- `/map`、`/compare`、`/trips`：全程深色。这些是工具页面，颜色不变，避免干扰操作。
- `/`、`/places/[id]`：按章节交替，深色开头，深色结尾。
- `/places`：深色。
- 实现方式：每个章节标记 `data-theme="dark"` 或 `data-theme="light"`，章节内用同一组变量名取色。章节滚动到屏幕中线时，页面底色用 600ms 过渡到下一种。

## 4. 字体

全站使用系统字体，和 Apple 官网的做法一致。不用宋体，不下载字体文件。

```css
--font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text",
  "PingFang SC", "Helvetica Neue", "Microsoft YaHei", "Noto Sans SC", sans-serif;
--font-mono: "SF Mono", ui-monospace, Menlo, Consolas, monospace;
```

在苹果设备上显示为 SF Pro 和苹方；在 Windows 上显示为微软雅黑；在安卓上显示为思源黑体。SF Pro 的授权不允许把字体文件放到网站上分发，所以用系统字体的方式调用。

### 4.1 字号层级

| 名称 | 电脑 | 手机 | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|
| 巨型 | `clamp(96px, 16vw, 280px)` | `clamp(64px, 22vw, 96px)` | 700 | 0.95 | 首页首屏、页脚压边的大字，每页最多两处 |
| 展示 | 80px | 44px | 600 | 1.05 | 章节里的一句话陈述 |
| 标题一 | 56px | 36px | 600 | 1.07 | 页面标题 |
| 标题二 | 40px | 28px | 600 | 1.1 | 章节标题 |
| 标题三 | 28px | 22px | 600 | 1.14 | 卡片标题、景点名 |
| 小标题 | 21px | 19px | 600 | 1.19 | 面板标题 |
| 大正文 | 21px | 19px | 400 | 1.38 | 导语 |
| 正文 | 17px | 17px | 400 | 1.47 | 正文、对话内容 |
| 说明 | 14px | 14px | 400 | 1.43 | 来源、时间、标签 |
| 小字 | 12px | 12px | 400 | 1.33 | 图片署名、脚注 |
| 角标 | 11px 等宽 | 11px 等宽 | 400 | 1.3 | 四角的技术信息，字母大写，字间距 0.08em |

- 中文不调字间距。英文和数字在 40px 以上时字间距 -0.02em，巨型为 -0.03em。
- 字重只用 400、600、700 三种。
- 强调用金色或加粗，不用下划线和斜体。
- 正文每行不超过 36 个汉字。

|---|---|---|
| 页面左右边距 | 48px | 22px |
| 正文内容最大宽度 | 980px | 100% |
| 宽内容最大宽度（卡片网格） | 1200px | 100% |
| 章节上下留白 | 128px | 72px |

## 7. 组件

### 7.1 导航栏

- 悬浮在页面顶部，高 48px，左右边距同页面。
- 毛玻璃底：深色章节上是 `rgba(14, 15, 17, 0.72)`，浅色章节上是 `rgba(245, 245, 247, 0.72)`，加 `backdrop-filter: saturate(180%) blur(20px)`。
- 导航文字 14px；当前页面的文字用金色。
- 最右边是"开始规划"胶囊按钮，高 32px。
- 向下滚动时导航栏收起，向上滚动时出现。
- 手机上只显示标志、"开始规划"和菜单按钮；菜单全屏展开，菜单项用标题一的字号。

### 7.2 按钮

| 类型 | 样子 | 用途 |
|---|---|---|
| 主按钮 | 金色底 `#C9A45C`，字 `#0E0F11`，高 44px，左右内边距 22px，字号 17px | 每屏最多一个，例如"开始规划"、"发送" |
| 次按钮 | 透明底，1px 暗金边框，金色字，尺寸同上 | 例如"查看档案" |
| 文字链接 | 金色字，后面带一个"›"，悬停时"›"右移 4px | 例如"查看全部景点 ›" |
| 图标按钮 | 44px 圆形，浮层底色 | 2D/3D 切换、关闭、菜单 |

- 悬停：主按钮变亮金，300ms。按下：缩小到 0.97。
- 所有可点击元素的点击范围不小于 44 × 44px。
- 键盘聚焦时显示 2px 金色外框，距元素 2px。

### 7.3 景点照片卡片

- 比例 4:5（竖图），圆角 28px，照片铺满。
- 文字压在照片下方的渐变上：从透明到 `rgba(14, 15, 17, 0.85)`，占卡片下方 55%。
- 内容从上到下：区域和类别（说明字号，金色）、景点名（标题三）、一行简介（说明字号）。
- 悬停：照片放大到 1.05，卡片不动，600ms。
- 占位照片的右上角显示"占位"标签，左下角用小字显示作者和许可。

### 7.4 信息卡片和面板

- 底色用 `--surface`，圆角 18px，不加阴影。深色底上靠底色差区分层次；浅色底上加 1px `--line` 边框。
- 面板标题用小标题字号。

### 7.5 状态标签

- 胶囊形，高 24px，左右内边距 10px，说明字号。
- 1px 状态色边框，状态色文字，透明底。
- 文字固定为：已核实、待确认、占位、已过期、校验通过、校验未通过。

### 7.6 四角信息

- 学自 laxspace.co：屏幕四角放小号等宽文字，像仪表读数。
- **只显示程序真实得到的值**：当前坐标、缩放级别、2D/3D 状态、当前模型、校验结果、景点数量（由程序数出来）。不放编出来的数字。
- 颜色用弱文字色；手机上不显示。

### 7.7 对话面板（在 `/map`）

- 用户消息靠右，浮层底色；AI 消息靠左，无底色。圆角 18px。
- 输入框高 44px 起，圆角 22px，右侧是圆形的金色发送按钮。
- 规划进行时逐步显示当前阶段的文字（理解需求、筛选景点、生成行程、校验），不用假的进度百分比。

## 8. 动效

### 8.1 时间和缓动

| 名称 | 时长 | 用途 |
|---|---|---|
| 微交互 | 150ms | 按下、开关 |
| 界面 | 300ms | 悬停、面板展开 |
| 显现 | 600ms | 内容滚动出现、章节变色、图片放大 |
| 主视觉 | 1000ms | 首屏标题、地图镜头移动 |
| 转场 | 800ms | 黑幕开场和换页 |

```css
--ease-standard: cubic-bezier(0.28, 0.11, 0.32, 1);
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
```

出现用 `--ease-out`，其余用 `--ease-standard`。

### 8.2 动效清单

| 编号 | 动效 | 来源 | 用在哪里 | 做法 |
|---|---|---|---|---|
| 1 | 黑幕开场 | laxspace | 每次打开网站的第一个页面 | 黑屏中央显示小号"WUHAN MEMORY."，随后黑幕向上揭开。总时长不超过 1.8 秒，同一次访问只播一次，点击可跳过 |
| 2 | 黑幕转场 | laxspace | 页面之间跳转 | 黑幕从下往上盖住再揭开，共 800ms。进入 `/map` 时缩短到 400ms |
| 3 | 巨型标题 | 两者 | 首页首屏、页脚 | 首屏"武汉记忆"逐字从下方升起；页脚左右各一个大字压在屏幕底边，中间一条细线连接 |
| 4 | 滚动显现 | trevornoah | 首页、景点详情 | 内容进入屏幕时上移 24px 并淡入，同组元素依次延迟 80ms |
| 5 | 陈述句逐词点亮 | trevornoah | 首页的一句话介绍 | 展示字号的一句话，随滚动从弱文字色逐词变为主文字色，关键词变金色 |
| 6 | 章节变色 | trevornoah、Apple | 首页、景点详情 | 见 3.5 |
| 7 | 图片飘入 | trevornoah | 首页景点章节 | 几张景点照片以不同速度随滚动移动，最大位移 80px |
| 8 | 3D 主体 | laxspace | 首页首屏 | 用高德 3D 地图做主体：倾斜俯视的武汉，随滚动缓慢旋转和拉近。不引入单独的 3D 引擎。没有 key 或加载失败时显示一张静态图 |
| 9 | 四角信息 | laxspace | 首页首屏、`/map` | 见 7.6 |
| 10 | 磁吸按钮 | 两者 | "开始规划"主按钮 | 鼠标靠近时按钮向鼠标偏移最多 6px。只在电脑上启用 |
| 11 | 地图镜头 | 自己 | `/map` | 生成行程后镜头飞到第一天；切换天数时飞到当天范围；路线从起点画到终点；标记依次落下 |
| 12 | 卡片悬停 | Apple | 所有卡片 | 见 7.3 |

### 8.3 动效规则

- 只对 `transform` 和 `opacity` 做动画，保证流畅。
- 不劫持滚动：页面滚动速度和方向始终由用户控制，不做强制整屏翻页。
- 系统开了"减弱动态效果"（`prefers-reduced-motion`）时：关掉 1、2、3、5、7、8、10 的位移和旋转，只保留淡入；地图镜头改为直接切换。
- 手机上关掉 7、8 的滚动联动和 10；首屏的 3D 地图改为静态图，节省流量和电量。
- `/map` 页面里除了 11 和基本的悬停、展开，不加装饰性动效。
- 动效不能挡住内容：任何内容在 1 秒内必须可读、可点。

### 8.4 实现方式

- 滚动和进出场动画使用 `motion` 库（React 动画库）；简单的悬停和过渡直接用 CSS。
- 3D 主体使用高德 JS API 自带的 3D 视图，通过地图 provider 接口调用。
- 新增依赖由 Cecilia 在 Mac 终端安装，板块 1 开工时确认。

## 9. 占位内容

Cecilia 还没提供的景点照片和简介，先用网上的资料占位，规则如下：

- **照片**：优先使用可自由使用的图片（例如维基共享资源上 CC BY、CC BY-SA、CC0 或公有领域的图）。每张记录作者、许可、原始链接和下载日期。不使用无法确认授权的图片。
- **简介**：根据官方页面的内容用自己的话概括，不复制原文。每条记录来源链接和查阅日期。
- **开放时间、票价等会变的信息**：可以从官方页面摘录事实，但必须记录来源链接和查阅日期，并标为"待确认"。找不到官方来源时写 `TODO(Cecilia)`，不猜。
- **标记**：所有占位内容在数据里标 `placeholder: true`，在界面上显示"占位"或"待确认"标签，照片旁显示作者和许可。
- **评价**不占位。评价只用 Cecilia 和试用过的朋友写的。
- Cecilia 提供自己的照片和核实过的资料后，替换占位内容并去掉标记。数据检查脚本会列出还剩多少占位内容。

## 10. 无障碍和手机

- 正文对比度不低于 4.5，大字不低于 3。
- 所有功能可以只用键盘完成，聚焦位置可见。
- 图片有文字说明；装饰性图片对读屏软件隐藏。
- 手机上内容单列排布，不出现横向滚动。
- `/map` 在手机上：地图全屏，对话和行程在底部可上拉的面板里。
