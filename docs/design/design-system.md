# WuhanMemory 设计规范

版本: v2 草案，2026-11-14
状态: 待 Cecilia 确认。

v2 相对 v1 的改动（都来自 Cecilia 的意见）：配色统一为黑金，去掉浅色章节；字体不再参考 Apple，改为参考两个参考网站的排版；新增插画体系；动效加强"丝滑"的部分；官网照片可以作为占位。

本文件取代开工说明第 5 节原来的设计方向。板块 1 起所有界面按本文件实现；要改数值时先改本文件，再改代码。

## 1. 设计方向

一句话：**黑底上的金色城市档案，像一本会动的画册。**

从两个参考网站学视觉传达的方法，不学它们的颜色和素材：

| 来源 | 学什么 |
|---|---|
| trevornoah.com | 极大的粗体标题撑满屏幕；立体小物件和带白边的剪贴照片随滚动飘进飘出；一句话占一屏的叙事节奏；胶囊按钮 |
| laxspace.co | 极细的小字和极大的字形成对比；屏幕中央一个可以转动的 3D 主体；大量留白；黑幕开场和转场；四角的技术信息小字 |

两个网站共同的手法是**对比**：字号的极大和极小、字重的极粗和极细、静止的留白和运动的主体。本规范的每一部分都围绕这一点。

只参考手法，不复制参考网站的图片、文字、代码和字体文件。

## 2. 页面结构

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 首页（展示页） | 滚动叙事，介绍武汉、景点和这个网站能做什么 |
| `/map` | 地图工作台 | 核心功能：AI 对话 + 地图 + 行程面板。打开就能用，不需要滚动 |
| `/places` | 地点档案 | 大图卡片，可筛选 |
| `/places/[id]` | 景点详情 | 单个景点的滚动叙事页 |
| `/compare` | 模型对比 | 千问和豆包并排 |
| `/trips` | 我的行程 | 生成过的行程列表 |
| `/s/[slug]` | 分享页 | 只读 |

导航项：首页标志、**地图**、**地点档案**、**模型对比**、**我的行程**，最右边是金色胶囊按钮"开始规划"，指向 `/map`，在任何页面都可见。

## 3. 颜色

全站只有黑和金两个色系。不使用浅色背景。

### 3.1 色板

| 名称 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 墨黑 | `--bg` | `#0B0B0C` | 页面底色 |
| 暖黑 | `--bg-warm` | `#12100C` | 交替章节的底色，和墨黑只有很小的差别，用来分段而不突兀 |
| 卡片 | `--surface` | `#161514` | 卡片、面板 |
| 浮层 | `--surface-raised` | `#1E1C1A` | 悬停、弹出层、输入框 |
| 细线 | `--line` | `#2B2824` | 分隔线、边框 |
| 主文字 | `--text` | `#EDE8DD` | 标题和正文（暖白，不用纯白） |
| 次要文字 | `--text-secondary` | `#A9A294` | 说明、时间、来源 |
| 弱文字 | `--text-muted` | `#847D70` | 占位提示、四角信息 |
| 金 | `--gold` | `#C8A45A` | 强调字、主按钮、选中状态、插画线条 |
| 亮金 | `--gold-bright` | `#E6CB8A` | 悬停、高光 |
| 暗金 | `--gold-deep` | `#8C7038` | 细线、次要按钮边框、插画暗部 |
| 金上文字 | `--on-gold` | `#0B0B0C` | 金色按钮上的字 |

### 3.2 金箔渐变

```css
--gold-foil: linear-gradient(100deg, #8C7038 0%, #E6CB8A 38%, #C8A45A 62%, #8C7038 100%);
```

只用在三个地方：首屏巨型标题、插画的描边高光、章节之间的分隔细线。鼠标移动或页面滚动时，渐变的位置缓慢移动，像金箔反光。其他地方的金色一律用纯色，避免满屏发光。

### 3.3 质感

- 全页覆盖一层很淡的颗粒噪点（不透明度 4%），让黑色有纸的质感，不是屏幕的死黑。
- 大面积的黑不加渐变光晕。层次靠墨黑、暖黑、卡片三级底色区分。

### 3.4 金色的用量

一屏之内金色面积不超过约十分之一。金色出现的地方就是要用户看的地方。

### 3.5 状态色

状态信息需要和金色区分开，所以保留三个低饱和的状态色，只用在小标签上。

| 含义 | 色值 | 用在哪里 |
|---|---|---|
| 已核实、校验通过 | `#7FB094` | 来源标记、校验结果 |
| 待确认、占位内容 | `#8FA3B5` | 还没核实的信息、占位照片和简介 |
| 已过期、校验失败、出错 | `#E0765F` | 过期数据、错误提示 |

状态不能只靠颜色区分，必须同时有文字。

### 3.6 对比度

由脚本按 WCAG 公式算出，正文要求不低于 4.5。

| 文字 | 背景 | 对比度 |
|---|---|---|
| 主文字 `#EDE8DD` | 墨黑 `#0B0B0C` | 16.1 |
| 次要文字 `#A9A294` | 墨黑 | 7.76 |
| 次要文字 `#A9A294` | 卡片 `#161514` | 7.19 |
| 弱文字 `#847D70` | 墨黑 | 4.82 |
| 弱文字 `#847D70` | 卡片 | 4.47（卡片上的弱文字只用于 14px 以上的非关键信息） |
| 金 `#C8A45A` | 墨黑 | 8.35 |
| 暗金 `#8C7038` | 墨黑 | 4.21（只用于线条和边框，不用于正文） |

## 4. 字体

参考两个网站的排版方式：trevornoah.com 用很粗、很紧凑的无衬线大字；laxspace.co 用很细的小字配很大的字。两者用的都是付费字体（Die Grotesk、Brockmann），不能直接拿来用，所以选气质相近、可以免费商用的字体。

### 4.1 字体选择

| 用途 | 字体 | 说明 |
|---|---|---|
| 英文和数字 | **Inter Tight**（可变字重 100 到 900） | 开源（OFL 许可）。紧凑的瑞士风格无衬线体，粗的时候接近 trevornoah 的大标题，细的时候接近 laxspace 的小字 |
| 中文大标题 | **思源黑体 Noto Sans SC**，字重 900 | 开源（OFL 许可）。只用于巨型和展示级标题 |
| 中文正文 | 系统字体：苹方、微软雅黑 | 不下载，保证打开速度。正文用细体 |

```css
--font-display: "Inter Tight Variable", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
--font-body: "Inter Tight Variable", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

字体文件通过 `@fontsource` 安装到项目里，和网站一起提供，不依赖国外的字体服务。中文字体按字符分片加载，浏览器只下载页面用到的那部分。安装命令由 Cecilia 在 Mac 终端运行，板块 1 开工时给出。

### 4.2 字号层级

| 名称 | 电脑 | 手机 | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|
| 巨型 | `clamp(120px, 19vw, 340px)` | `clamp(72px, 24vw, 120px)` | 900 | 0.88 | 首页首屏、页脚。撑满屏幕宽度，允许被屏幕边缘裁切一部分 |
| 展示 | 96px | 48px | 800 | 1.0 | 一句话占一屏的陈述 |
| 标题一 | 64px | 40px | 700 | 1.05 | 页面标题 |
| 标题二 | 40px | 28px | 700 | 1.1 | 章节标题、景点名 |
| 标题三 | 24px | 20px | 600 | 1.2 | 卡片标题、面板标题 |
| 导语 | 22px | 18px | 300 | 1.5 | 章节开头的一段话 |
| 正文 | 16px | 16px | 300 | 1.7 | 正文、对话内容 |
| 说明 | 13px | 13px | 300 | 1.5 | 来源、时间 |
| 标签 | 11px | 11px | 400 | 1.3 | 小标签、四角信息、编号。英文全大写，字间距 0.14em；中文字间距 0.3em |

### 4.3 排版规则

- **粗细对比**：标题用 700 到 900，正文用 300。不使用 400 到 500 的中间字重做正文，保持对比。
- **大小对比**：巨型或展示级的大字旁边，直接配 11 到 13px 的标签小字，中间不放中等字号。
- 英文大标题字间距 -0.04em，中文大标题字间距 -0.02em。
- 展示级陈述里，关键词用金色，其余用主文字色；还没读到的词用弱文字色（见动效 5）。
- 每个章节左上角有一个编号标签，例如 `01 / 城市`，用标签字号。
- 正文每行不超过 34 个汉字。
- 细体小字只用在墨黑或暖黑底上，并保证不小于 13px（标签除外），确保看得清。

## 5. 间距和版面

基础单位 4px。可用的间距：4、8、12、16、24、32、48、64、96、128、192。

| 项目 | 电脑 | 手机 |
|---|---|---|
| 页面左右边距 | 40px | 20px |
| 正文内容最大宽度 | 720px | 100% |
| 宽内容最大宽度 | 1320px | 100% |
| 章节上下留白 | 192px | 96px |
| 卡片之间的间隔 | 24px | 16px |

- 首页和景点详情页大量留白：一屏只讲一件事。
- 版面允许不对称：标题靠左、插画压到右边缘之外、照片错落摆放。
- 断点：手机小于 734px，平板 734 到 1068px，电脑大于 1068px。

## 7. 组件

### 7.1 导航栏

- 悬浮在页面顶部，高 48px。底色 `rgba(11, 11, 12, 0.6)` 加背景模糊 20px。
- 左边是标志"武汉记忆"（标题三字号，700）；中间是导航项（标签字号）；右边是"开始规划"胶囊按钮和一个圆形菜单按钮。
- 当前页面的导航项下方有一个金色小圆点。
- 向下滚动时收起，向上滚动时出现。
- 菜单打开时全屏展开：黑幕落下，菜单项用展示字号依次升起，鼠标指到哪一项，哪一项变金色，旁边浮出对应的插画。

### 7.2 按钮

| 类型 | 样子 | 用途 |
|---|---|---|
| 主按钮 | 金色底，墨黑字，高 48px，左右内边距 28px，字号 15px，字重 600 | 每屏最多一个 |
| 次按钮 | 透明底，1px 暗金边框，金色字 | 次要操作 |
| 文字链接 | 金色字加箭头"→"，下方一条细线；悬停时细线从左到右重新画一遍，箭头右移 | 例如"查看全部景点 →" |
| 圆形按钮 | 48px 圆形，1px 细线边框 | 菜单、2D/3D 切换、关闭 |

- 主按钮悬停：金色底从左下角被亮金填满（像液体涌入），300ms。按下：缩小到 0.96。
- 所有可点击元素的点击范围不小于 44 × 44px。
- 键盘聚焦时显示 2px 金色外框。

### 7.3 景点照片卡片

- 比例 4:5，圆角 28px，照片铺满。
- 文字压在照片下方的渐变上：从透明到 `rgba(11, 11, 12, 0.9)`，占卡片下方 55%。
- 内容：编号和区域（标签字号，金色）、景点名（标题二）、一行简介（说明字号）。
- 悬停：照片放大到 1.06 并略微去掉暗色遮罩；卡片随鼠标位置轻微倾斜（最多 4 度）；右下角浮出一个金色圆形的"查看"提示。
- 占位照片右上角显示"占位"标签，左下角用标签字号显示来源。

### 7.4 信息卡片和面板

- 底色 `--surface`，圆角 18px，1px `--line` 边框，不加阴影。
- 标题用标题三；每个面板左上角可以有一个标签字号的类别名。

### 7.5 状态标签

- 胶囊形，高 24px，左右内边距 10px，标签字号。
- 1px 状态色边框，状态色文字，透明底。
- 文字固定为：已核实、待确认、占位、已过期、校验通过、校验未通过。

### 7.6 四角信息

- 屏幕四角放标签字号的小字，像仪表读数。
- **只显示程序真实得到的值**：当前坐标、缩放级别、2D/3D 状态、当前模型、校验结果、景点数量（由程序数出来）、当前滚动到第几章。不放编出来的数字。
- 手机上不显示。

### 7.7 对话面板（在 `/map`）

- 用户消息靠右，浮层底色；AI 消息靠左，无底色。圆角 18px。
- 输入框高 48px 起，圆角 24px，右侧是圆形金色发送按钮。
- 规划进行时逐步显示当前阶段的文字（理解需求、筛选景点、生成行程、校验），每个阶段完成时前面的小圆点变金色。不用假的进度百分比。

## 8. 插画

插画是 v2 新增的部分，用来增加艺术感，承担参考网站里"立体小物件"和"屏幕中央主体"的角色。

### 8.1 题材

和旅行、武汉有关的物件和地标。先做一组 8 到 10 个，题材清单由 Cecilia 确认，例如：黄鹤楼、长江大桥、江汉关钟楼、东湖、樱花、编钟、轮渡、热干面、地铁票、相机、行李箱、地图图钉。

插画只画物件的样子，不附带事实性说明。

### 8.2 风格

统一的规则，保证所有插画像出自同一人之手：

- **只用黑和金**：墨黑底，金色和暗金两种线条，最多加一处暖白高光。不用其他颜色。
- **剪贴感**：每个物件是一个独立的"贴纸"，外圈有一圈描边，可以叠在照片和大字上（学自 trevornoah.com 的剪贴手法）。
- **立体感**：物件带一点俯视角度和一块柔和的投影，像摆在桌面上（学自两个网站的立体主体）。
- **留白**：一屏最多三个物件，周围留出足够的空。

### 8.3 两种制作方式

| 方式 | 做什么 | 谁来做 |
|---|---|---|
| 代码绘制的线描插画（SVG） | 金色线条勾勒的地标和物件。线条可以做"一笔一笔画出来"的动画 | Claude 直接写 |
| 图像模型生成的立体物件 | 黑金配色的立体小物件图片，去背景后当贴纸用，更接近 trevornoah.com 的效果 | Claude 写提示词，Cecilia 用图像生成工具生成，再放进项目 |

Claude 在这个开发环境里不能直接生成图片，只能写代码绘制。第二种方式是否采用、用哪个工具，由 Cecilia 决定。无论哪种方式，都不描摹参考网站里的具体图案。

### 8.4 插画怎么动

- 进入屏幕时：线描插画的线条从无到有画出来（1.2 秒）；立体物件从屏幕外飘入并轻微旋转。
- 停留时：缓慢上下浮动（幅度 8px，周期 6 秒），每个物件的节奏不同。
- 滚动时：不同物件以不同速度移动，产生前后层次。
- 鼠标靠近时：物件向鼠标方向轻微偏移和倾斜。

### 8.5 首屏的主体

首页首屏中央放一个主体，承担 laxspace.co 里 3D 物体的角色。两个方案，板块 1 开工时由 Cecilia 选：

- 方案 A：金色线描的武汉地形，长江和汉江在中间交汇，三镇用细线勾出，随滚动缓慢旋转倾斜。用代码绘制，不需要 key，加载快。
- 方案 B：高德 3D 地图的真实武汉，调成黑金配色，随滚动旋转拉近。真实感强，但需要 key，加载慢一些，手机上要换成静态图。

## 9. 动效

目标是"丝滑"：动作连贯、有惯性、不突然开始也不突然停下。

### 9.1 时间和缓动

| 名称 | 时长 | 用途 |
|---|---|---|
| 微交互 | 200ms | 按下、开关 |
| 界面 | 400ms | 悬停、面板展开 |
| 显现 | 900ms | 内容出现、图片放大 |
| 主视觉 | 1400ms | 首屏标题、插画线条、地图镜头 |
| 转场 | 900ms | 黑幕开场和换页 |

```css
--ease-silk: cubic-bezier(0.16, 1, 0.3, 1);      /* 快速启动，很长的减速尾巴，用于出现和移动 */
--ease-inout: cubic-bezier(0.65, 0, 0.35, 1);    /* 用于幕布和遮罩 */
```

不使用匀速（linear）和回弹（bounce）。

### 9.2 全局的丝滑处理

| 编号 | 处理 | 做法 |
|---|---|---|
| G1 | 惯性滚动 | 电脑上给页面滚动加一点惯性，松开滚轮后页面继续滑行一小段再停下。方向和距离仍由用户控制，不做强制翻页。手机上用系统自带的滚动 |
| G2 | 自定义光标 | 电脑上光标变成一个 10px 的金色小圆点，带一点延迟跟随鼠标。指到可点击的元素时放大成 56px 的圆环，圆环里显示"查看"、"拖动"、"打开"等提示字 |
| G3 | 换页转场 | 点击链接后，金色细线从左到右划过屏幕，黑幕随之落下再揭开，新页面的内容依次升起。进入 `/map` 时缩短到 450ms |
| G4 | 元素延续 | 从地点档案点进景点详情时，被点击的照片卡片直接放大成详情页的头图，不是消失再出现 |
| G5 | 颗粒和金箔 | 见 3.2 和 3.3 |

### 9.3 动效清单

| 编号 | 动效 | 用在哪里 | 做法 |
|---|---|---|---|
| 1 | 黑幕开场 | 每次打开网站的第一个页面 | 黑屏中央一个小号的"WUHAN MEMORY"标签和一条从 0 画到 100% 的金色细线，随后黑幕向上揭开。不超过 2 秒，同一次访问只播一次，点击可跳过 |
| 2 | 巨型标题 | 首页首屏、页脚 | "武汉"和"记忆"分列屏幕左右，每个字从下方的遮罩里升起；金箔渐变随鼠标移动。向下滚动时两组字向两侧分开，露出中间的主体 |
| 3 | 主体 | 首页首屏 | 见 8.5。可以用鼠标拖动旋转 |
| 4 | 滚动显现 | 所有内容 | 文字按行从遮罩里升起，同组元素依次延迟 90ms |

### 9.4 动效规则

- 只对 `transform` 和 `opacity` 做动画，保证流畅。
- 任何内容在 1.5 秒内必须可读、可点。动效不能让用户等。
- 系统开了"减弱动态效果"（`prefers-reduced-motion`）时：关掉 G1、G2、6、7、8、10 和所有位移旋转，只保留淡入；地图镜头改为直接切换。
- 手机上：关掉 G1、G2、10 和卡片倾斜；7 改成用手指横向滑动；首屏主体用简化版本。
- `/map` 页面里只有 13、14 和基本的悬停、展开，不加装饰性动效，保证核心功能好用。
- 低性能设备上自动降级：检测到帧率持续偏低时，关闭颗粒、视差和主体的旋转。

### 9.5 实现方式

- 滚动联动和进出场：`motion` 库（React 动画库）。
- 惯性滚动：`lenis` 库。
- 插画：SVG，线条动画用描边偏移实现。
- 首屏主体方案 A 用 SVG 或 Canvas；方案 B 用高德 JS API 的 3D 视图，通过地图 provider 接口调用。
- 新增依赖都是开源许可，由 Cecilia 在 Mac 终端安装，板块 1 开工时给出命令并确认。
